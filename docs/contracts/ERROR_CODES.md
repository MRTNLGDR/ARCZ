# Catálogo de erros estruturados V5

A API usa o envelope:

```json
{
  "error": {
    "code": "GENERATOR_INPUT_MISSING",
    "message": "entrada local obrigatória ausente",
    "retryable": false,
    "details": {},
    "trace_id": "uuid"
  }
}
```

A lista abaixo documenta códigos existentes no código. Não renomeie sem manter
compatibilidade/migração.

### Regras

- erro de entrada normalmente não é retryable;
- timeout/transient worker pode ser retryable conforme details;
- erro nunca vira HTTP 200 com `ok: true`;
- stack/segredo não sai na resposta pública;
- `trace_id` liga API, job, log e diagnóstico local.
