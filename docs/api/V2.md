# API local V2

Base: `http://127.0.0.1:<porta>/api/v2`. A URL é local; nenhuma rota exige internet.

## Diagnóstico e catálogo

- `GET /health`
- `GET /diagnostics`
- `GET /network`
- `GET /profiles`
- `GET /profiles/{id}`
- `GET /plugins`
- `GET /plugins/{id}`
- `GET /sources?kind=osm`
- `GET /models`
- `GET /panoramas`
- `GET /panoramas/{id}`

## Região e geração

- `POST /regions/resolve`
- `POST /regions/context`
- `POST /profiles/compose`
- `POST /profiles/infer`
- `POST /tiles/plan`
- `POST /budget`
- `POST /budget/release`
- `POST /generation/inputs/resolve`
- `POST /generation/jobs`
- `GET /generation/jobs`
- `GET /generation/jobs/{id}`
- `GET /generation/jobs/{id}/events` — SSE
- `POST /generation/jobs/{id}/cancel`

## Importação e capacidades locais

- `POST /sources/import` — aceita somente caminho relativo dentro de `data/imports/inbox`;
- `POST /geocoder/import`;
- `POST /panoramas/verify`;
- `POST /ai/tools` — broker local, erro se modelo não estiver instalado;
- `POST /sheets/compose` — job local;
- `POST /plugins/{id}/validate`.

## Erros

```json
{
  "error": {
    "code": "INPUT_MISSING",
    "message": "...",
    "retryable": false,
    "details": {},
    "trace_id": "..."
  }
}
```

HTTP 2xx nunca significa que um job terminou: criação retorna `202` e o cliente deve acompanhar estado/SSE até status terminal.
