# Acervo open source controlado

- `upstream/`: checkout original e imutável por commit.
- `forks/`: cópias de trabalho controladas; nunca fonte de provenance.
- `integrations/`: manifests, patches e estratégias de atualização.
- `manifest.json`: fonte machine-readable.

Esta entrega não contém uma cópia falsa do Aedifex nem do Cesium. Os bytes
externos ausentes permanecem bloqueios explícitos.
